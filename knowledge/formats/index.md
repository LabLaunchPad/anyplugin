# Interoperability Format

* [AGENTS.md open standard](agents-md.md) - Linux-Foundation-stewarded AGENTS.md spec, per-agent precedence rules, and how the four target agents consume it.
* [MCP server configuration shapes](mcp-config.md) - Exact MCP server config schema per target agent — TOML vs JSON variants, field names, timeouts — used by adapters when emitting server registrations.
* [Open Knowledge Format (OKF) v0.2](okf-v02.md) - Google Cloud's OKF v0.2 spec extraction — frontmatter fields, reserved files, conformance rules, trust tiers — the authority for the knowledge/ library in agent-prism core.
* [SKILL.md standard (agentskills.io)](skill-md.md) - The shared skill format adopted by all four target agents, with per-agent frontmatter differences and search paths — the strongest portability bridge.

# Your Plugin Starter

Generated by `anyplugin init --name my-plugin`. This directory contains everything
needed to build a native plugin for all four AI coding agents: Claude Code,
OpenCode, Codex CLI, and Antigravity.

## Files

| File | Role |
|------|------|
| `anyplugin.plugin.yaml` | **Canonical manifest** — edit `name`, `version`, `description`, hooks, skills, commands, agents, MCP, knowledge, ladder, intensity |
| `hooks/before-tool.mjs` | **Hook handler template** — `run(payload)` must return `{ block?, reason?, additionalContext?, permissionDecision?, systemMessage?, raw? }` |
| `knowledge/getting-started.md` | **OKF knowledge bundle** — read `index.md` first, then only relevant concept files via the `okf-reader` skill |
| `skills/hello/SKILL.md` | **Skill template** — per agentskills.io format; `name` + `description` are required for implicit invocation |
| `knowledge/index.md` | **Progressive disclosure navigation** — navigation/progressive disclosure ONLY; must declare `okf_version: "0.2"` at root |

## Quick Start

```bash
# 1. Edit the manifest (anyplugin.plugin.yaml) — set name, version, description, and desired hooks/skills/commands
# 2. Write your hook handler in `hooks/` (model the returned HookResult shape)

# 3. Build for all agents
npx @lablaunchpad/cli build --plugin .

# 4. Install into a target agent
npx @lablaunchpad/cli install --plugin . --project ./my-repo

# 5. Validate your OKF bundle
npx @lablaunchpad/cli okf-validate knowledge
```

If you have the CLI installed (`npm install @lablaunchpad/cli`), the
shorter `anyplugin ...` form works too — the package installs a binary
with that name.

## Hook Handler Shape

Your `run(payload)` must return a `HookResult`:

```javascript
{
  block?: boolean,           // true → agent tool is blocked (exit 2 on Antigravity, exit 0 non-blocking elsewhere)
  reason?: string,           // human-readable reason for block/deny
  additionalContext?: string,// injected into the agent's session context
  permissionDecision?: 'allow' | 'deny', // for permission-asked / permission-request events
  systemMessage?: string,    // sent as a system-level message to the agent
  raw?: unknown              // passed through as-is to the agent
}
```

## Skill Template (skills/hello/SKILL.md)

```yaml
name: hello-skill
description: A simple skill that responds with a greeting and the plugin name
```

## Intensity & Ladder

Your manifest can include:

```yaml
intensity:
  conservative: "Only run safe, well-tested tools"
  balanced: "Run tools with moderate risk assessment"
  aggressive: "Experiment with new tools and patterns"

ladder:
  - "observation"
  - "lesson" 
  - "hypothesis"
  - "verified_knowledge"
```

Consult `docs/PATTERNS.md` for the full adoption record of intensity and ladder.

## Commands You'll Use

```bash
# Scaffold
npx @lablaunchpad/cli init --name my-plugin

# Build + install
npx @lablaunchpad/cli build --plugin . --out ./dist
npx @lablaunchpad/cli install --plugin . --project ./my-repo

# Intensity mode (writes to .anyplugin-mode in the installed root)
npx @lablaunchpad/cli intensity --mode aggressive

# OKF validation
npx @lablaunchpad/cli okf-validate knowledge
npx @lablaunchpad/cli okf-reindex knowledge
```
